# Harry Potter Database

This app allows you to search for characters from the Harry Potter universe and add them to your list of favorites.

### Testing notes

* Your favorite characters will be stored in your browser, and if you go to the “favorites” page you will see charts that summarize some of the characters’ attributes.  
* There are a few filters to play with (gender, species, house etc.)  
* Click on the “info” icon will reveal the blood status of the character if it’s known (pure blood, half blood or muggle)

### Stack

Made in Vanilla JS with the use of:

* [Potter DB](https://docs.potterdb.com/)  
* [Tailwind](https://tailwindcss.com/)   
* [Hyper UI](https://www.hyperui.dev/)  
* [Chart JS](https://www.chartjs.org/)
